# HX-20 S1000D Migration Case Study

Portfolio case study showing how a fictional legacy helicopter maintenance manual can be audited and restructured into a compact S1000D-style technical publication package.

## What this project demonstrates

- source manual audit and content classification
- data module planning with a mini DMRL
- S1000D-style data module codes
- separation of removal, installation and operational test content
- MK1/MK2 applicability handling
- publication module assembly
- ICN-style technical illustration handling
- engineering review notes for missing safety-critical source data

## Main files

- `index.html` - portfolio presentation page
- `HX20_Legacy_Helicopter_Manual.docx` - legacy source document
- `HX20_Legacy_Helicopter_Manual_Preview.pdf` - source preview
- `s1000d/` - simplified S1000D-style XML data modules and publication module
- `assets/ICN-HX20-A-291000-A-001-01.svg` - ICN-style illustration concept

## Important scope note

The aircraft and manual are fictional. The project does not invent safety-critical values such as torque, pressure, leakage rate or fitting sizes. Those items are marked as engineering-source data that would need approval before a production release.

This is a compact portfolio example, not a complete validated S1000D delivery.
